# Advanced AM Fabrication System

### ORGANIC — Horizon Europe Project

The **Advanced AM Fabrication System** is being developed within the Horizon Europe **ORGANIC project** to enable intelligent, adaptive and sustainable additive manufacturing of bio-inspired structures using bio-based composite materials.

The system builds upon Fused Granulate Fabrication (FGF) technology, integrating advanced sensing and monitoring capabilities, adaptive manufacturing strategies and self-X control mechanisms to improve process reliability, structural performance and resource efficiency.

### Main objectives

- **Advanced FGF fabrication:** Support large-scale additive manufacturing of bio-inspired structures using bio-based thermoplastic composites with variable fibre-length reinforcements.
- **Intelligent process monitoring:** Integrate sensing and data acquisition technologies to monitor critical manufacturing parameters, including temperature, pressure and deposited material geometry.
- **Adaptive toolpath planning:** Develop dynamic manufacturing strategies capable of adjusting deposition trajectories and process parameters based on real-time feedback.
- **Self-X process control:** Implement intelligent self-monitoring, self-optimisation and self-healing strategies to detect deviations and adapt manufacturing conditions.
- **First-Time-Right manufacturing:** Improve fabrication accuracy, process stability and product quality while reducing defects, material waste and energy consumption.

### Development status

The Advanced AM Fabrication System is under development as part of ORGANIC WP3 — Novel Fabrication Systems for Bio-Based Composites AM Processes.

This repository is intended to host publicly releasable software components, algorithms, documentation and supporting resources associated with the advanced fabrication system.

Software components and usage instructions will be made available as approved for public release.
